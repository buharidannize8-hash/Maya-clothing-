# MAYA CLOTHING

Maya Clothing is a modern streetwear e-commerce website powered by:

- HTML
- CSS
- JavaScript
- Supabase
- GitHub Pages

## Features

- Product listing
- Product categories
- Search
- Shopping cart
- Local cart storage
- Supabase authentication
- Customer orders
- Newsletter
- Responsive mobile design

---

# Setup

## 1. Create Supabase project

Go to:

https://supabase.com

Create a new project.

---

## 2. Create database

Open:

Supabase Dashboard
→ SQL Editor

Copy everything from:

supabase/schema.sql

Paste it into SQL Editor.

Run it.

---

## 3. Get Supabase credentials

Open:

Project Settings
→ API

Copy:

Project URL

and

Publishable / anon key.

---

## 4. Add credentials

Open:

config.js

Replace:

YOUR_SUPABASE_PROJECT_URL

and

YOUR_SUPABASE_ANON_KEY

with your real values.

---

# Run

You can upload the project to GitHub.

Enable:

GitHub
→ Settings
→ Pages

Select:

Deploy from branch

Branch:

main

Folder:

/root

Save.

Your Maya website will then be available through GitHub Pages.
